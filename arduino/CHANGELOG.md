# Changelog

## [1.0.0] - 2025-11-22

**Initial Release**

- MAX30102/MAX30100 I2C sensor support
- Analog pulse sensor support
- Serial communication (9600 baud)
- Heart rate detection algorithm
- BPM filtering (30-250 range)
- Configurable via `config.h`
- PlatformIO support
- Complete documentation
